Interactive Portfolio Website – UI/Frontend Challenge
## Overview
This project is a personal interactive portfolio website created as part of the
Survey Sparrow UI/Frontend challenge. The goal is to showcase UI design,
animations, and frontend development skills.

## Requirements Implemented
- Sticky header with navigation
- Personal information section with quick facts
- Animated hero section with smooth motion effects
- Interactive image gallery with hover and lightbox
- Responsive design for mobile and desktop
- Resume download feature

## Technologies Used
- HTML
- CSS
- JavaScript
- AOS for scroll animations
